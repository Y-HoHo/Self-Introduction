## reset.css 순서

- `기본 스타일 초기화`라서 `CSS`보다 먼저 불러와야한다. ( 태그가 가지는 기본 스타일 자체를 초기화 시켜버림 )
  - `reset.css`를 사용하는 이유 : 모든 스타일을 내가 직접 지정하겠다. 

- 현재 코드에서는 클래스 선택자를 사용해서 문제가 없어보인다.

- 하지만 `h3{}`처럼 태그 이름만으로 사용될 경우에는 `reset.css`가 덮어지게된다.
  - ex) `h3 {color: red;}` -> 적용이 안됨.

## Semantic Tag (시맨틱 태그 -> 의미있는 태그)

1. 접근성: 시각장애인이 쓰는 화면 낭독기의 기능떄문!

2. 검색엔진(SEO): 구글 같은 검색엔진이 페이지에서 어디가 중요한 본문인지 파악하기 쉽다!

3. 코드 가독성: 다른 개발자가 코드를 봤을 때 구조가 한눈에 보인다! div 지옥은 피하자... 
<br /><br />

"시맨틱 태그가 뭔가요?"라는 질문..
> "태그 이름으로 콘텐츠의 의미와 역할을 나타내는 HTML 태그입니다. header, nav, main, footer 같은 것들이 있고, 화면 낭독기 같은 보조기기의 접근성과 검색엔진 최적화에 유리하며 코드의 가독성도 좋아집니다."
<br /><br />

| 태그 | 의미 |
|:---|:---|
| header | 페이지나 구역의 머리말 (로고, 메뉴) |
| nav | 다른 곳으로 이동하는 메뉴 모음 |
| main | 페이지의 핵심 본문 (페이지당 하나) |
| section | 주제별로 묶인 구역 |
| article | 그 자체로 완결되는 글 (블로그 글, 뉴스 기사) |
| aside | 본문과 관련은 있지만 곁가지인 내용 (사이드바) |
| footer | 페이지나 구역의 꼬리말 (연락처, 저작권) |

## flex 속성: 부모 vs 자식

- **부모(컨테이너)에게 주는 속성**: `display: flex`, `gap`, `justify-content`, `align-items`
  - 자식들을 "어떻게 배치할지" 정한다.

- **자식(아이템)에게 주는 속성**: `flex: 1`, `flex-shrink` 등
  - 부모가 `display: flex`일 때만 작동한다!

- 내가 했던 실수
  - `gap`을 `li`에 줌 → 부모인 `ul`에 줘야 한다.
  - `flex: 1`을 `p`에 줌 → `p`의 부모(`.text`)는 flex가 아니라서 무시됨. flex 아이템인 `.text`에 줘야 한다.
